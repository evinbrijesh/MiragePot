### 3. Attacker Profiling System

**Skill Level Estimation** (`miragepot/server.py:_estimate_skill_level()`)
- Analyzes attacker sophistication using multi-factor heuristic:
  - **Command tier distribution** (filesystem vs. cache vs. LLM usage)
  - **TTP detection results** (stages, confidence, technique diversity)
  - **Honeytoken interaction** (credential access indicates targeted behavior)
  - **Session duration and command count**
- Three skill levels:
  - **Script Kiddie**: Random commands, high LLM tier usage, low sophistication
  - **Intermediate**: Mixed tactics, some reconnaissance, knows common paths
  - **Advanced**: Targeted actions, multi-stage attacks, credential exfiltration, low LLM usage

**Tier Usage Tracking** (`miragepot/command_handler.py`)
- Added `tier_usage` dict to session state: `{"filesystem": 0, "cache": 0, "llm": 0}`
- Increments appropriate counter for each command based on handling path:
  - **Filesystem tier**: Built-in commands (`cd`, `ls`, `pwd`, `cat`, etc.) + interactive handlers
  - **Cache tier**: Pre-cached responses for common utilities
  - **LLM tier**: Novel commands requiring AI generation
- Stored in session logs and used for skill level estimation at session end
- Enables understanding of attacker sophistication (advanced attackers use fewer LLM-tier commands)

**Profile Persistence**
- Profiles saved as JSON files in `data/profiles/session_{id}_{timestamp}.json`
- Added to `.gitignore` (generated at runtime, not committed)
- Docker volume mount for profile data persistence
- Dashboard reads profiles directly from filesystem

**Enhanced Login Banner** (`miragepot/server.py:_generate_login_banner()`)
- Generates realistic Ubuntu 22.04 MOTD (Message of the Day) with randomized system stats:
  - Load average (3 values), processes, memory/disk usage
  - Package updates available (0-87 packages, 0-15 security updates)
  - System restart notice
  - IPv4 address for eth0
- Enhances realism for attackers - mimics legitimate Ubuntu server experience
