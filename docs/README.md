## Documentation Structure

MiragePot documentation is split into two layers:

- `docs/info/`: report-ready, deeply technical docs (architecture, PRD/MVP, internals, deployment)
- `docs/`: operational/utility docs that are still useful day-to-day (install, usage, troubleshooting, offline deployment, etc.)

If you're writing a report, start here:

- `docs/info/REPORT_INDEX.md`
